## Projetos

### Ferramentas para estudo e organização

**Atlas PDF** — biblioteca de PDFs para Linux com busca, classificação por assunto e identificação de duplicatas. Combina React e Electron na interface, Python na indexação e SQLite no catálogo.

**Librarian** — aplicativo em C++ e Qt para explorar uma biblioteca em um salão interativo, com catálogo SQLite, pesquisa, favoritos e acesso a PDFs.
